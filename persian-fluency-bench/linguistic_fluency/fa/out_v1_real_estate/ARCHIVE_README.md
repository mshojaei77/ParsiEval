# Archive: v1 "Real-Estate Operator" Run (2026-01-06)

These are the results of the **first edition** of the benchmark, when every case used a
Tehran real-estate phone-operator persona and the judge demanded Tehrani colloquial
(mahavireh) in all answers.

Persian Fluency Bench v2 changed the purpose to general **Modern Native Persian linguistic
fluency** with two tracks:

- `casual` — chats, talking, replying (natural colloquial Persian)
- `formal` — writing books, articles, letters (eloquent standard Persian)

Scores in this archive were produced under the old single-register protocol and are
**not comparable** with v2 runs.

## Contents

- `fa_subject_outputs.jsonl` — raw subject-model responses
- `fa_judged.jsonl` — judge-scored rows
- `fa_summary.json` / `fa_report.md` — per-model aggregates
