# Konkur1404 Benchmark Leaderboard

This Space hosts the leaderboard for the [Konkur1404 Benchmark](https://github.com/mshojaei77/konkur-eval), evaluating Large Language Models on the Iranian University Entrance Exam (Konkur) 2025.

## Metrics
- **Text-Only Score (Primary):** Accuracy on questions without images. This allows fair comparison between text-only and multimodal models.
- **Standard Score:** Overall accuracy on the full dataset (text + images).
